## 📋 Project Overview

Family carers can face challenges finding suitable residential care, managing emotionally difficult transitions and navigating ongoing care needs for relatives living with dementia.

This project analysed accounts from two family carers, Susan and Louise, featured in a Dementia Australia podcast. The objective was to identify challenges across the residential-care journey and explore opportunities to improve care, family support and communication with care providers.
